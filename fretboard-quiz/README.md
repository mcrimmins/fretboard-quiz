# Fretboard Note Quiz

A tap-the-screen quiz for learning the notes on a guitar neck. Installable as an app (PWA), works offline.

**Modes:** Find it (tap the asked-for note) · Name it (name the highlighted note)
**Extras:** string / fret-range filters, sharps/flats, weak-spot weighting and heatmap.

Host with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root), then open the Pages URL in Chrome on Android and choose **Install app**.

When you change files, bump `VERSION` in `sw.js` so installed copies update.
